# Experimentele Joepie
Dit is de Repository die al de documenten bevat die ik gebruikt heb om het vak Experimentele Basistechnieken in de opleiding Fysica tot een goed einde te brengen.

## Welke map bevat wat?
| map | bevat | opmerkingen |
|-----|-------|-------------|
| P-mappen | foto's en andere random files die (meestal) in het verslag terecht zijn gekomen | niet zo nuttig |
| VS code | bevat alle code gebruikt voor de practica, is onderverdeeld per practicum  | niet al deze code is overzichtelijk, kijk op eigen risico |
| Verslagen | bevat de verslagen van de practica waar dit nodig was | niet altijd juist genummerd |
